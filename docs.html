Hacking on it?

Architecture first, then the IPC contract — every main ⇄ renderer call is typed in one file, and every engine is plain Node you can test without Electron.

Rules every decision respects

Engines never import Electron

Scanner, cleaners, duplicates, apps, stats, history, report — plain Node, smoke-testable standalone. Only the shell files touch Electron.

Deletes go to the Trash. Only.

Every removal is shell.trashItem — recoverable by design — behind a confirmation the user can, but must choose to, disable.

100% local, zero telemetry

No account, no analytics, no network calls in the app. The only thing that leaves the machine is what the user exports themselves.

The contract is typed

src/shared/ipc.ts is the single source of truth: preload, mock adapter and every view implement or consume the same SpectraApi.
