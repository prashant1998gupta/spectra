What's new.

Every release, honestly logged — from the first rough X-Ray alpha to today's 1.0. Spectra updates itself quietly; this page is the loud version.

v1.1.0 September 1, 2026

“Prism” — the intelligence layer

New
  • Insights — a storage health score built from five weighted factors, each showing its own sub-score and the sentence behind it. No unexplained numbers.
  • Storage Forecast — predicts when a drive actually fills up, using a median-of-slopes fit so one big install or delete cannot skew the date.
  • What Changed — diff two scans. Each folder is credited with its own growth rather than its children’s, so you get the culprit instead of a stack of parent directories.
  • Restore Center — every removal recorded (what, from where, how big, which screen asked) and put back from the Trash in one click.
  • App Footprint — what an app really occupies: the bundle plus every cache, container, support folder and log it scattered across your Library.
  • System Data — the Mac storage mystery itemised: snapshots, purgeable space, the sleep image, swap and evicted iCloud files, each marked reclaimable or system-managed.
  • Project Radar — dev projects ranked by git staleness rather than file dates, with the command that regenerates every artifact it offers to remove.
  • File Provenance — the download URL and the app that fetched it, read from the metadata macOS has kept all along.
  • Space Rules — your own thresholds, checked on the maintenance schedule. Rules only notify; nothing acts without you.
  • Archive & Offload — compress a folder to a single archive, optionally on another drive. The archive is read back and verified before the original moves to the Trash.
Improved
  • The live browser demo is now published at /demo/ — previously the “try the demo” button only scrolled to a paragraph describing one.
  • Every deletion across the whole app now records its origin, so Restore Center can name the screen that asked for it.
  • Scheduled maintenance evaluates your Space Rules; a rule you wrote yourself takes priority over the generic “junk is piling up” notification.
Fixed
  • Scan-diff attribution lost the filesystem root: the parent of /Users resolved to nothing rather than /, so a scan of the whole disk reported the root as one giant change echoing everything beneath it.
  • Corrected “Universal” throughout the site — Spectra ships two native builds, one per chip, which is exactly why the download page asks you to pick one.
  • Installer sizes now quoted in decimal MB, matching what Finder shows for the file you actually downloaded.
v1.0.0 August 30, 2026

"Aurora" — the first public release

New
  • Disk X-Ray — interactive treemap and sunburst of your entire disk, click-to-zoom down to single files
  • Smart Clean — caches, logs, browser junk, old installers and stale iOS backups in one reviewed pass
  • Dev Cleaner — Xcode junk, stale node_modules, Docker leftovers and package-manager caches
  • Duplicate Finder — byte-identical copies, verified by cryptographic hash
  • Large & Old Files — the forgotten giants, sorted for the easiest wins first
  • App Uninstaller — removes apps together with their scattered leftovers
  • Startup Items manager — see and switch off login items and launch agents
  • Live Monitoring — CPU, RAM, network and battery, always a keystroke away
  • Storage Timeline — a running history of your free space
  • Scheduled scans with a quiet menu-bar presence
  • HTML report export — clean, self-contained, auditable reports
  • Spectra Pro — one-time US$11.99 lifetime license at launch (regularly $16.99)
Improved
  • Full-disk scan now completes in under a minute on Apple Silicon
  • Native builds for Apple Silicon and Intel — the download page detects which one you need
  • Ignore lists now sync across all analysis and cleaning views
Fixed
  • Treemap tiles no longer flicker when a scan updates mid-hover
  • Correct free-space reporting on volumes with APFS local snapshots
  • Menu-bar icon respects reduced-transparency and increased-contrast settings
v0.9.2 beta July 21, 2026

Release-candidate polish

New
  • Sunburst view — a second lens on the X-Ray, ring-by-ring through your folder tree
  • 5 themes — Aurora, Daylight, Midnight, Solar and Mono (three are Pro)
  • Demo mode now runs in the browser, no install needed to explore
Improved
  • Scan engine rewritten for lower memory use on 8 GB Macs
  • Full keyboard navigation and VoiceOver labels across every view
  • Smart Clean summaries now show per-item paths before you confirm
Fixed
  • Rare crash when a scanned volume was ejected mid-scan
  • Timeline chart mislabeled weeks that crossed a month boundary
